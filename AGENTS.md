# Project Guidance

## Project
- This repository is a small static website whose entry point is `index.html`.
- There is currently no build system, package manager, or automated test suite.

## Working in this repository
- Keep changes focused and use standard HTML, CSS, and browser JavaScript unless the project gains an established dependency or build setup.
- Preserve responsive behavior, semantic markup, and accessibility when adding site features.
- Avoid introducing tooling or dependencies for changes that can be handled directly in the static page.

## Verification
- For HTML or styling changes, inspect `index.html` in a browser at desktop and mobile widths.
- For JavaScript behavior, verify the changed interaction in the browser and check the developer console for errors.
- There are no repository-defined build or test commands at this time.
