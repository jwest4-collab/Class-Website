# Class-Website

## Accessibility updates

- I added a descriptive document title, page language, main landmark, and one primary heading on each page.
- I added a skip link, named the navigation landmark, and marked the current page link for keyboard and assistive-technology users.
- I added alternative text and a caption for the portrait, and replaced unfinished profile text with meaningful content.
- I added visible labels, required-field instructions, hints, and a fieldset with a legend to the contact form.
- I added inline validation messages, an announced error summary, and `aria-invalid` states that update when the user corrects a field.
- I added visible keyboard focus indicators and maintained readable text and control borders across the shared palette.
- I applied the same stylesheet and navigation design to all three pages so presentation and interactions remain consistent.
- I made the main content focusable so the skip link moves keyboard focus to the start of each page.
- I checked every used text/background pairing with WebAIM's Contrast Checker against the WCAG AA 4.5:1 threshold: body text on paper/white/soft is 12.2:1/13.1:1/11.2:1, headings on white/soft/paper are 9.80:1/8.40:1/9.09:1, links on white/soft are 9.11:1/7.81:1, navigation links are 7.28:1, normal/hover button text is 5.20:1/9.80:1, muted text on paper/white is 6.91:1/7.45:1, and error text on white is 9.12:1.
- I checked the form control border with WebAIM at 4.57:1, exceeding WCAG's 3:1 minimum for user-interface components.


## Visual design

- I used **proximity** by grouping related project cards and form fields with consistent gaps and spacing.
- I used **similarity** through repeated card borders, heading styles, and navigation treatments to show which content belongs together.
- I used a consistent teal, coral, warm-white, and charcoal palette across every page.
